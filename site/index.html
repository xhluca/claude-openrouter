OpenRouter models in Claude Code

Your models. Claude's picker.

Add OpenRouter favorites to Claude Code's native /model menu while preserving your Claude.ai login and connectors. No proxy or background service.

curl -LsSf https://xhluca.github.io/claude-openrouter/install.sh | sh

Run clor search to search the live catalog, clor select to choose favorites, and clor claude to start an OpenRouter session. Your ordinary claude command remains a native session.

Your OpenRouter key stays in a local mode-0600 credential file. With a native Claude.ai login, connectors remain available and the external-auth warning is absent. Reset tool data with clor reset.
