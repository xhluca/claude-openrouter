OpenRouter models in Claude Code

Your models. Claude's picker.

Add OpenRouter favorites beside Claude's built-in models in the native /model menu while preserving your Claude.ai login, connectors, and Max billing for Claude models.

curl -LsSf https://xhluca.github.io/claude-openrouter/install.sh | sh

Run clor search to search the live catalog, clor select to choose favorites, and plain claude to start. The same configuration works with claude --agent, background agents, and the claude agents view.

A fail-closed loopback router keeps provider credentials separate: Claude models go only to Anthropic, and labeled OpenRouter favorites go only to OpenRouter. Secret-bearing files stay local with mode 0600. Reset everything with clor reset.
